## 📦 Installation & Setup

### Prerequisites
- Node.js 18+
- npm or yarn

### Local Development

```bash
# Clone repository
git clone https://github.com/arenasbob2024-cell/devtoolbox.git
cd devtoolbox

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3000
```

### Build for Production

```bash
# Build the site (requires 4GB RAM)
NODE_OPTIONS='--max-old-space-size=4096' npm run build

# Start production server
npm run start
```

### Generate Sitemaps

After adding new tools:

```bash
node scripts/generate-static-sitemap.js
```

## 🔧 How to Add a New Tool

### 1. Define the Tool

Add to `src/lib/tools.ts`:

```typescript
{
  id: 'my-tool',
  name: 'My Tool',
  description: 'Brief description',
  icon: 'tool-icon-name',
  category: 'Category',
  keywords: ['keyword1', 'keyword2'],
  path: '/tools/my-tool',
  relatedTools: ['tool-1', 'tool-2', 'tool-3', 'tool-4'],
}
```

### 2. Create Page Components

**`src/app/[lang]/tools/my-tool/layout.tsx`:**
```typescript
export const generateMetadata = ({ params }: Props) => {
  const dict = await getDictionary(params.lang);
  return {
    title: dict.tools['my-tool'].pageTitle,
    description: dict.tools['my-tool'].pageDescription,
    // ... other metadata
  };
};
```

**`src/app/[lang]/tools/my-tool/page.tsx`:**
```typescript
'use client';
import { ToolLayout } from '@/components/ToolLayout';
import { useLang } from '@/i18n/LangContext';

export default function MyTool() {
  const dict = useLang();
  return (
    <ToolLayout toolId="my-tool">
      {/* Your tool component */}
    </ToolLayout>
  );
}
```

### 3. Add Translations

Update all 15 language files in `src/i18n/dictionaries/`:

```json
{
  "tools": {
    "my-tool": {
      "name": "My Tool",
      "description": "Description",
      "pageTitle": "Page title for SEO",
      "pageDescription": "Page description for SEO"
    }
  }
}
```

### 4. Regenerate Sitemap

```bash
node scripts/generate-static-sitemap.js
```

### 5. Submit PR

1. Test locally: `npm run dev`
2. Build: `NODE_OPTIONS='--max-old-space-size=4096' npm run build`
3. Create pull request

## 🤝 Contributing

We welcome contributions! Here's how to help:

### Ways to Contribute

1. **Add a tool** - Follow the [tool template](#-how-to-add-a-new-tool)
2. **Improve translations** - Help with language files
3. **Fix bugs** - Submit issues and PRs
4. **Write blog posts** - Add tutorials to `src/data/blog-posts.ts`
5. **Suggest tools** - [Open an issue](https://github.com/arenasbob2024-cell/devtoolbox/issues)

### Development Guidelines

- Follow existing code style (TypeScript, Tailwind CSS)
- All new tools must include translations for all 15 languages
- Test locally before submitting PR
- Ensure build passes: `NODE_OPTIONS='--max-old-space-size=4096' npm run build`
